# Mengzhen Li

Personal academic website and project portfolio for Mengzhen Li, a computer science graduate from Xiamen University Tan Kah Kee College in China (June 2026).

## Research

My undergraduate research focused on control algorithms and simulation for a dual-quadrotor UAV system. I worked on a Fuzzy CPSO-BP neural-network PID controller and evaluated its performance in simulation. I am interested in aerial robot control, robust and adaptive control, and moving from simulation to hardware experiments.

## Selected work

- **UAV control:** dual-quadrotor control research, simulation results, and related publication.
- **UE5 game development:** project overview and selected visual materials.
